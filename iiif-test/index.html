静的IIIFを使った デジタルアーカイブ の例

このページは、静的IIIF (IIIF Level 0) を使ったデジタルアーカイブの例です。 IIIF は International Image Interoperability Framework の略称です。 デジタル化された文化資源を、標準的な方法で表示・操作できるようになります。 一般的には、IIIFのマニフェストはサーバーサイドで動的に生成されることが多いですが、この例では、静的なJSONファイルとしてマニフェストを python で生成し、表示しています。 すべての画像とマニフェストは、GitHub Pages上でホスティングされています。
このページのソースコードは、GitHubで公開されています。https://github.com/umemotollc/hijiri/tree/main/iiif-test
